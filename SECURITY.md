# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. **Do not disclose it publicly.**

    - Please avoid posting the vulnerability on public forums, GitHub issues, or any other public channels.

2. **Contact the maintainers directly.**

    - Send an email to [alifm2101@gmail.com](mailto:alifm2101@gmail.com) with the details of the vulnerability.
    - Include as much information as possible to help us understand and reproduce the issue.

3. **Wait for a response.**

    - We will acknowledge receipt of your report within 48 hours and provide a timeline for a fix.

4. **Coordinate disclosure.**
    - Once the issue is resolved, we will work with you to disclose the vulnerability responsibly.

Thank you for helping us keep this project secure.
